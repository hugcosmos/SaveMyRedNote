<h1 align="center">Save My RedNote 🍠</h1>

<p align="center">Backup your Xiaohongshu notes locally, preview & deploy to Cloudflare Pages.</p>

<blockquote>If your Xiaohongshu account gets suspended, these notes are your only memory.</blockquote>

---

## Quick Start

```bash
git clone git@github.com:hugcosmos/SaveMyRedNote.git
cd SaveMyRedNote
pip install Pillow
```

Prerequisites:
- Install [BrowserSkill extension](https://chromewebstore.google.com/detail/browserskill/hhcmgoofomhgciiibhipgmgkgnoenaoi) in Chrome
- Install `bsk` CLI ([guide](https://github.com/Tencent/BrowserSkill))
- Log in to xiaohongshu.com in Chrome
- Verify `bsk session list` shows your browser

### Get Cookie

```bash
python3 xhs_collect.py auth SESSION_ID
```

Copy Cookie from Chrome F12 → Network → first request → Request Headers → Cookie: → Copy value.

### One Command

```bash
python3 xhs_collect.py run-all SESSION_ID
```

Auto: fetch notes → download images → watermark → build preview page.

> ⚠️ If your account was banned, name/avatar/bio may be reset. Fix them in `admin.html`.

### Preview

```bash
python3 xhs_collect.py serve
```

Open http://localhost:8088

## Configuration

Priority: **localStorage(admin) > config.json > DEFAULTS**

Three ways to configure:
1. `config.json` — auto-generated by scripts
2. `admin.html` — browser UI (localStorage)
3. DEFAULTS in `index.html` — hardcoded, visible to all visitors

### AI Translation

```bash
export AGNES_API_KEY=sk-your-key
python3 xhs_collect.py translate
```

Get a key from [Agnes AI](https://agnes-ai.com). Without it, the page still works — English version unavailable.

## Deploy to Cloudflare

```bash
python3 xhs_collect.py build
```

Upload to Cloudflare Pages (Direct Upload):

```
index.html  data.js  manifest.json  images_wm/
```

No build command needed.

## Commands

| Command | Description |
|---------|-------------|
| `auth SESSION` | Paste cookie |
| `list SESSION` | Fetch note list + profile |
| `extract` | Bulk extract note details |
| `images` | Download original images |
| `comments SESSION` | Extract comments (author only) |
| `comments SESSION --full` | Extract all comments |
| `watermark` | Add watermarks |
| `translate` | AI translate (needs AGNES_API_KEY) |
| `build` | Generate preview pages |
| `serve` | Local preview server |
| `run-all SESSION` | Full automated pipeline |

CDN URLs stripped at build time. API keys and cookies never included in preview pages.
