<h1 align="center">Save My RedNote</h1>

<p align="center">Backup your Xiaohongshu notes locally, preview & deploy to Cloudflare Pages.</p>

> If your Xiaohongshu account gets suspended, these notes are your only memory.

---

## ⚠️ Disclaimer

For personal backup only. **Default mode stores only your own posts and your author replies — no other user data is saved.** Respect others' privacy and copyright.

---

## Quick Start

```bash
git clone git@github.com:hugcosmos/SaveMyRedNote.git
cd SaveMyRedNote
pip install Pillow
```

**Prerequisites:**
- Install [BrowserSkill extension](https://chromewebstore.google.com/detail/browserskill/hhcmgoofomhgciiibhipgmgkgnoenaoi) in Chrome
- Install `bsk` CLI ([guide](https://github.com/Tencent/BrowserSkill))
- Log in to xiaohongshu.com in Chrome
- Verify `bsk session list` shows your browser

### 1. Get Cookie

```bash
python3 xhs_collect.py auth SESSION_ID
```

Run the command, then: Chrome F12 → Network → refresh → click first request → find Cookie: in Request Headers → right-click Copy value → paste into terminal.

### 2. One Command

```bash
python3 xhs_collect.py run-all SESSION_ID
```

Auto: fetch notes → download images → watermark → build preview.

> ⚠️ Banned accounts get name/avatar/bio reset by platform. Fix in `admin.html`.

### 3. Preview

```bash
python3 xhs_collect.py serve
```

Open http://localhost:8088

## Configuration

Priority: **admin(localStorage) > config.json > DEFAULTS**

**config.json** — auto-generated by scripts:

```json
{ "authorName": "Your Name", "authorUserId": "your_id", ... }
```

**admin.html** — browser UI, saves to your localStorage only.

**DEFAULTS** — hardcoded in `index.html`, visible to all visitors.

### AI Translation (optional)

```bash
export AGNES_API_KEY=sk-your-key
python3 xhs_collect.py translate
```

Without it, only UI text (Home, Follow, etc.) translates. Note titles, content and comments stay in Chinese.

---

## Deploy to Cloudflare

```bash
python3 xhs_collect.py build
```

Upload to Cloudflare Pages:

```
index.html  data.js  manifest.json  images_wm/
```

## Commands

| Command | Description |
|---------|-------------|
| `auth SESSION` | Paste cookie |
| `list SESSION` | Fetch notes + profile |
| `extract` | Extract note details |
| `images` | Download images |
| `comments SESSION` | Comments (author only) |
| `comments --full` | All comments |
| `watermark` | Add watermarks |
| `translate` | AI translate (needs API key) |
| `build` | Generate preview files |
| `serve` | Local preview |
| `run-all SESSION` | Full pipeline |

## Collected Data

| Data | Default | `--full` mode |
|------|---------|---------------|
| Your notes | ✅ Saved | ✅ Saved |
| Your comments | ✅ Saved | ✅ Saved |
| Your replies | ✅ Saved | ✅ Saved |
| Others' comments | ❌ Not saved | ✅ Saved |
| Others' avatars/names/IDs | ❌ Not saved | ✅ Saved |
| Image CDN URLs | ❌ Stripped at build | ❌ Stripped at build |
| API Key / Cookie | ❌ Not in page | ❌ Not in page |
| Your config | In .gitignore | --- |
